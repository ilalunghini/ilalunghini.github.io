EEG Inverse Solution and Connectivity Analysis

MATLAB course project for Analisi e Modellazione dei Sistemi Biologici (Analysis and Modelling of Biological Systems). This private repository preserves the coursework implementation and its helper functions.

Aim

Starting from high-density EEG recordings, a template MRI, electrode locations, cortical-surface resources, and an atlas, the analysis estimates cortical source activity and analyses connectivity between atlas-defined regions of interest.

The final goal is to reconstruct source activity with eLORETA, parcellate it into 100 atlas-defined regions, estimate delta-band partial directed coherence, and visualize directed connectivity and weighted node strength.

Project Overview

The workflow combines a three-layer boundary-element head model, eLORETA source reconstruction, atlas-based parcellation, partial directed coherence, and network-strength visualization.

1. EEG loading and head-model construction

EEG data are loaded through EEGLAB and converted to a FieldTrip structure. A template MRI is segmented to construct a three-layer boundary-element head model, while cortical solution points define the source space.

2. Electrode alignment and inverse solution

Electrode locations are aligned to the head model, and a lead field is computed. Source activity is then estimated with eLORETA.

3. Source interpolation and parcellation

Source activity is interpolated to the template MRI and parcellated with a 100-region atlas, producing region-of-interest time series and source-level measures.

4. Connectivity and network analysis

Delta-band partial directed coherence is estimated between regions. The connectivity matrix is visualized and converted into BrainNet Viewer node and edge files; weighted node strength is then visualized on the brain surface.

Requirements

  • MATLAB;
  • FieldTrip;
  • EEGLAB;
  • GIFTI support for MATLAB;
  • BrainNet Viewer;
  • access to the authorised EEG data and external MRI, atlas, and cortical-surface resources.

Implementation

The workflow uses FieldTrip for MRI segmentation, BEM head-model construction, lead-field calculation, eLORETA source analysis, atlas parcellation, spectral analysis, and partial directed coherence estimation.

Supporting routines normalize connectivity values and prepare BrainNet Viewer-compatible network visualizations. The analysis computes weighted node strength from the connectivity matrix for surface visualization.

Results

With authorised data, the workflow produces source-level activity, atlas-parcellated region-of-interest time series, a delta-band partial directed coherence matrix, BrainNet connectivity visualizations, and weighted node-strength maps.

No figures or results derived from the course dataset are included in this repository.
