Gait Kinematics with Joint Coordinate Systems

MATLAB course project for Basi di Analisi del Movimento (Fundamentals of Movement Analysis). The project estimates right lower-limb kinematics from stereophotogrammetric marker trajectories recorded during treadmill walking.

Aim

The objective is to reconstruct the motion of the tibia, calcaneus, metatarsus, and foot from marker coordinates, then quantify their relative motion over repeated gait cycles.

The analysis produces:

  • joint-angle trajectories in three anatomical components for Ankle 1 (tibia-calcaneus), calcaneus-metatarsus, and Ankle 2 (tibia-anatomical foot);
  • sagittal-plane angular velocities of the tibia, anatomical foot, and Ankle 2;
  • visual checks of the static and dynamic segment coordinate systems.

Analysis workflow

1. Static calibration

The static trial defines a Cartesian coordinate system for each segment. Each system has an origin and three unit vectors. Marker-to-marker vectors provide anatomical directions; cross products create perpendicular directions; normalization ensures that every axis has unit length.

The resulting axes form a right-handed rotation matrix, while the selected origin gives the segment position. Together, they define a homogeneous transformation matrix for the segment.

Segment or system Origin Geometric principle used to define orientation
Tibia Midpoint of RMMA and RANK The ankle markers define a mediolateral direction; the fibular-head direction and cross products complete the tibial frame.
Calcaneus Centroid of RCA1, RCA2, RLCA, and RSTL Rearfoot-marker planes and the static support-plane normal define the calcaneal orientation.
Metatarsus Centroid of RD1M, RD5M, and RP5M Metatarsal-marker geometry and the toe direction define the forefoot frame.
Technical foot Heel-region marker A marker-based frame provides a stable rigid-body reference for foot tracking.
Anatomical foot Heel-region marker A heel-to-toe direction is projected onto the technical-foot plane to define an anatomically meaningful forward axis.

Static marker positions are then expressed in their own segment reference systems. These local marker configurations are rigid templates: they describe the geometry of each segment independently of its position in the laboratory.

2. Dynamic segment localization

During walking, the same markers are observed in the laboratory reference system at every frame. For each segment, the code aligns its static local template with the dynamic marker configuration using SVD-based least-squares rigid-body registration.

This estimates the rotation and position that best fit all available markers at that frame. Using multiple markers reduces reliance on an individual marker and provides a stable estimate of segment pose.

The script visualizes selected frames to verify that the coordinate systems remain attached to the appropriate segments throughout the gait trial.

3. Relative rotations and joint angles

Joint motion is calculated from the relative rotation between a distal segment and its proximal segment:

Joint Proximal segment Distal segment
Ankle 1 Tibia Calcaneus
Calcaneus-metatarsus Calcaneus Metatarsus
Ankle 2 Tibia Anatomical foot

Each relative rotation is decomposed into the three components requested for the assignment:

Component Interpretation
e1 Plantarflexion / dorsiflexion
e2 Internal / external rotation
e3 Inversion / eversion

4. Gait-cycle normalization

The acquisition provides the start and end frame of five gait cycles. Because their durations differ slightly, each trajectory is resampled to 101 points, representing 0–100% of a gait cycle. This permits direct comparison between cycles and supports the joint-angle and angular-velocity plots produced by the script.

5. Sagittal angular velocity

Angular velocity is estimated from the frame-to-frame derivative of the segment rotation matrix. The script reports the sagittal component for the tibia, anatomical foot, and their relative motion at Ankle 2.

The sampling frequency is set to 100 Hz in the current implementation. This value must match the acquisition setting before absolute angular-velocity magnitudes are interpreted.

Requirements

  • MATLAB with page-wise matrix operations and singular-value decomposition support.

Gait-cycle normalization uses base-MATLAB linear interpolation with both event endpoints included; no Signal Processing Toolbox is required.
