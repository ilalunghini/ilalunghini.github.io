Franka Panda Peg-and-Ring Pick-and-Place

Academic robotics simulation for Principi di Robotica e applicazioni alla chirurgia in the Ingegneria dei Sistemi Medicali per la Persona programme. A Franka Panda manipulator places three colour-coded rings onto their matching pegs in CoppeliaSim.

Aim

Starting from a CoppeliaSim scene containing a Franka Panda robot, three colour-coded rings, and matching pegs, the project controls the manipulator through Cartesian target motion and inverse kinematics.

The goal is to place each ring onto the peg of the same colour. The user selects the first ring; afterward, the controller selects the closest remaining ring with a greedy nearest-neighbour policy.

Project Overview

The project demonstrates Cartesian target control, inverse kinematics, waypoint-based motion, grasp-offset compensation, and greedy task sequencing.

1. Scene interpretation and waypoint planning

The controller operates in the CoppeliaSim world frame and queries the positions of the rings and pegs from the scene. For each ring, it computes a safe pose above the ring, a pick pose at its outer edge, a transport pose above the matching peg, and a placement pose at the peg.

The waypoint layout was designed to keep movement controlled in a constrained workspace, reflecting a key consideration in surgical robotics: when space around the robot is limited, deliberate clearance above objects and pegs helps avoid unnecessarily wide or low movements. The safe heights provide clearance over the pegs while the Cartesian segments keep the motion easy to inspect and reproduce.

2. Cartesian motion and inverse kinematics

The inverse-kinematics target follows linearly interpolated Cartesian trajectories between the waypoints. CoppeliaSim's internal IK solver converts the desired target pose into joint motion for the Panda arm.

3. Grasp-offset compensation and task sequencing

To place the ring accurately, the controller computes the offset between the gripper's edge grasp point and the ring centre. It preserves this offset when computing the placement pose, aligning the ring with the target peg.

After the user-selected first ring, the controller estimates the Euclidean distance from the current target position to each remaining ring's pick pose and selects the smallest distance.

Requirements

  • CoppeliaSim with the ZeroMQ Remote API available;
  • Python 3;
  • the required Python package.

The original materials do not record the exact CoppeliaSim or Python version used to develop and test the project. Use a CoppeliaSim version compatible with the ZeroMQ Remote API and retain the scene's object names and hierarchy.

Implementation

The project uses the CoppeliaSim ZeroMQ Remote API from Python. The controller:

  • advances a stepped simulation for deterministic waypoint updates;
  • controls the Panda through a Cartesian IK target;
  • opens and closes the two gripper fingers;
  • estimates ring radius from the scene object's bounding box; and
  • simulates grasping by temporarily parenting a ring to the gripper tip during transport.

The parent-child attachment is an intentional simulation simplification. It is not a physics-based contact or grasp-stability model.

Skills demonstrated

  • Python programming and external simulator control;
  • CoppeliaSim scene interaction through the ZeroMQ Remote API;
  • Cartesian motion planning with waypoint interpolation;
  • inverse-kinematics-based robot control;
  • coordinate-frame reasoning and geometric offset compensation;
  • greedy nearest-neighbour task sequencing.

Results

The reported outcome is successful colour-matched placement of all three rings. The controller implements pose handling, IK-based waypoint motion, grasp-offset compensation, sequential execution, and greedy ring selection for this task.

No quantitative performance study, physical grasp validation, or trajectory-optimization comparison was part of the original project.
