Task-Based fMRI GLM Analysis

MATLAB course project for Analisi e Modellazione di Sistemi Biologici (Analysis and Modelling of Biological Systems). This implementation fits a voxelwise general linear model to task-based fMRI data, modelling motor execution and motor imagery conditions with HRF-convolved regressors and producing t-statistic maps for each condition.

Aim

Starting from a preprocessed 4D fMRI image, a brain mask, and motor-execution and motor-imagery task protocols, the analysis estimates voxelwise task effects with a general linear model (GLM).

The final goal is to produce t-statistic maps for each condition and visualize thresholded activation overlays relative to the mean fMRI anatomy.

Project Overview

The script loads a preprocessed 4D fMRI image and brain mask, then performs the following analysis steps.

1. Task-regressor construction

The two task protocols are loaded and each is convolved with SPM12's canonical hemodynamic response function. The resulting motor-execution and motor-imagery regressors are used to model the task conditions.

2. Design matrix and temporal filtering

A design matrix is built from the motor-execution regressor, motor-imagery regressor, and an intercept. DCT-based temporal high-pass filtering is then applied.

3. Voxelwise model fitting and statistical maps

An ordinary least-squares GLM is fitted at each voxel inside the brain mask. The analysis computes t-statistics and uncorrected two-sided p-values for each task regressor, then displays unthresholded t-statistic maps and thresholded activation overlays.

Requirements

  • MATLAB;
  • SPM12;
  • MATLAB Statistics and Machine Learning Toolbox;
  • authorized fMRI data in NIfTI format.

Implementation

The workflow constructs HRF-convolved task regressors, applies DCT-based temporal high-pass filtering, fits an ordinary least-squares GLM within the brain mask, and calculates t-statistics and uncorrected two-sided p-values for the task regressors.

Results

When run with authorized data, the final visualization displays all 36 slices, comparing thresholded motor-execution and motor-imagery t-statistic maps side by side.

Each map is overlaid on the mean fMRI image and thresholded at two-sided p < 0.05 (uncorrected), with non-significant voxels shown as transparent. The hot colormap displays t-values from 0 to 10, with brighter colours indicating stronger positive t-statistic values among the displayed effects.
