EEG microstate connectivity: a methodological pipeline for healthy controls and multiple sclerosis

An interactive, step-by-step walkthrough of the EEG microstate connectivity-analysis pipeline.

01 — Microstatessignal representation
01 / 13 · EEG → GFP → GFP peaks → scalp maps → clustering.
01 / Signal to microstates

Microstates

EEG microstates are brief periods in which the scalp-potential pattern remains relatively stable. They are thought to reflect coordinated activity across distributed brain regions.

EEG → GFP → GFP peaks → scalp topographies → clustering.

02 / GFP peaks

Keep the most informative moments.

The modified k-means procedure uses Global Field Power peaks rather than every sample. This improves signal-to-noise ratio and keeps clustering computationally tractable.

ClustPar.UseAAHC        = false;
ClustPar.MinClasses     = 6;
ClustPar.MaxClasses     = 6;
ClustPar.Restarts       = 100;
ClustPar.MaxMaps        = inf;
ClustPar.GFPPeaks       = true;
ClustPar.IgnorePolarity = true;
ClustPar.Normalize      = true;
03 / Individual maps

Six maps for one participant.

For each participant, scalp topographies at GFP peaks are grouped with modified k-means to identify six recurring microstate classes. The resulting maps describe the patterns found in that participant’s EEG.

[EEG, CURRENTSET] = pop_FindMSMaps(ALLEEG, AllSubjects, 'ClustPar', ClustPar);
04 / Group template

From individual to group.

Individual maps are combined within HCs and PwMS, producing a group-level mean map set while maintaining the six-class structure.

EEG = pop_CombMSMaps(ALLEEG, GroupIdx{g}, 'MeanName', ['Mean_' groupNames{g} '_' condNames{g}{1}], 'IgnorePolarity', ClustPar.IgnorePolarity);
05 / Grand-Grand Mean

Grand-Grand Mean

The two group templates are combined into the Grand-Grand Mean: the shared population-level reference carried forward into sorting and backfitting.

Individual → Group → Population.

EEG = pop_CombMSMaps(ALLEEG, [GroupMeanIdx{:}], 'MeanName', 'GrandGrandMean', 'IgnorePolarity', ClustPar.IgnorePolarity);
06 / Sorting

Sorting

The Grand-Grand Mean is matched to the Koenig 2002 reference. Individual and group maps are then sorted against the Grand-Grand Mean, keeping class labels A, B, C, D, E, and G consistent and comparable with prior studies.

[ALLEEG, EEG, CURRENTSET] = pop_SortMSMaps(ALLEEG, SortIdx, 'TemplateSet', GrandGrandMeanIdx, 'Classes', N_CLASSES, 'IgnorePolarity', ClustPar.IgnorePolarity);
07 / Backfitting

Backfitting

The sorted microstate maps are fitted back to the continuous EEG signal. At each eligible time point, the scalp pattern is assigned to its best-matching template map, producing a sequence of microstate labels for temporal analysis.

[EEG, CURRENTSET] = pop_FitMSMaps(ALLEEG, AllSubjects, 'TemplateSet', GrandGrandMeanIdx, 'FitPar', FitPar);
08 / Temporal variables

Describe state dynamics.

The fitted sequence yields occurrence, mean duration, coverage, individual explained variance, and total explained variance where applicable. These variables are compared between groups with rank-sum tests.

09 / Orthogonalized AEC

Measure connectivity inside each state.

Orthogonalized amplitude-envelope correlation (AEC) measures whether the amplitudes of two EEG channels rise and fall together during a microstate. For each participant and frequency band, we select the samples assigned to that microstate and derive amplitude envelopes using the Hilbert transform. We orthogonalize each channel pair in both directions to reduce the influence of shared zero-lag activity, then average the two correlations into one symmetric connectivity value.

10 / Edge vectors

Compare each independent connection.

Every connectivity matrix is reduced to its upper triangle. HC and PwMS edge-value distributions are compared using a Mann–Whitney rank-sum test for each band and microstate.

pVec(e) = ranksum(HC(:,e), PW(:,e));
11 / Graph measures

Connectivity becomes a weighted graph.

Each connectivity matrix is represented as a weighted, undirected graph: electrodes are nodes, and off-diagonal AEC values define connection weights. Graph metrics describe how strongly electrodes connect, how the network is organized, and how efficiently information can travel through it.

The pipeline calculates:

  • Degree, closeness, betweenness, and eigenvector centrality
  • Clustering coefficient, path length, and efficiency
  • Modularity and assortativity
12 / Summaries, tests & ranking

Graph features

Subject-level graph measures are summarized by mean and skewness. We compare graph features between HCs and PwMS, then examine effect sizes and ROC/AUC to see which features distinguish the groups. Rank-sum tests and node-wise FDR correction keep the statistical interpretation separate from that exploratory ranking.

Features: frequency band · mean/skewness · graph metrics

[p, h, stats] = ranksum(xHC, xPW);
pVals(ch) = p;

if isfield(stats, 'zval') && ~isempty(stats.zval)
    effVals(ch) = stats.zval / sqrt(nSub);
end
